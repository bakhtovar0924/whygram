# WHYGRAM v1 (MVP)

Whygram-like frontend on React (JS only) + json-server.

## Run

```bash
npm install
npm run server
npm run dev
```

- App: http://localhost:3000
- API: http://localhost:4000

## Pages

- `/login` `/register`
- `/` Home feed
- `/top` Explore grid
- `/profile` Profile
- `/reels` `/chat` `/settings`

## Stack

React + Vite + JS/JSX + Tailwind + MUI + axios + react-router-dom + json-server
